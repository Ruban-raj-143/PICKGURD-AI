# PickGuard AI — One-Minute Capstone Pitch (60 Seconds)

**Time Target:** ~60 Seconds

> *"Fulfilment centre pick operators process thousands of items daily. When an item is missing or damaged, operators face confusion: Should they recount? Check adjacent bins? Or update inventory? Unguided decisions lead to order delays, phantom stock, and costly warehouse errors.*
>
> *Enter **PickGuard AI** — an evidence-grounded AI decision assistant built on LangGraph, FastAPI, and React.*
>
> *Instead of relying on ungrounded LLM guesses, PickGuard AI uses deterministic Python tools to fetch verified inventory records, retrieves official SOP procedures via ChromaDB vector RAG, and synthesizes historical incident evidence. An LLM reasons over this evidence package while a deterministic safety policy automatically **BLOCKS** dangerous actions like inventory modifications.*
>
> *For high-risk exceptions, the system triggers a real LangGraph `interrupt()` checkpoint, pausing execution until a human supervisor reviews the evidence and submits an explicit decision via `Command(resume=...)` — guaranteeing zero autonomous warehouse state mutations.*
>
> *All 93 automated tests are passing, providing an enterprise-ready foundation for safe, evidence-grounded fulfilment operations."*
